User Configuration Manager
A lightweight Python module designed to manage, format, and validate user settings. This project demonstrates core Python data structure manipulation, focusing on dictionary operations, tuple unpacking, and input validation.

Features
Data Validation: Enforces case-insensitive constraints (lowercase conversion) to prevent duplicate or conflicting configuration keys.

CRUD Operations: Includes independent functions to add, update, delete, and view settings (add_setting, update_setting, delete_setting, view_settings).

Error Handling: Prevents silent failures by returning specific feedback messages when attempting to overwrite existing keys or modify non-existent ones.

Structured Output: Formats raw dictionary data into clean, readable text summaries.

Technical Details
Language: Python 3

Concepts Applied: Dictionaries, Tuples, String manipulation (f-strings), and conditional logic.
